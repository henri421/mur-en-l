L-shaped retaining wall

Stability and sections of an L-shaped retaining wall, Eurocodes of both generations.

The recommended values of the standards are proposed by default; each partial factor can be changed, for instance to apply a national annex. Check these values before any use on a real structure.

Variable actions
Name ψ0 γQ A1, EQU γQ A2 Remove

Without a described action, all Q loads form a single action “Q”. Each action leads in turn, the others at ψ0 (EN 1990, 6.10). Empty γQ: profile value. LM1: ψ0 = 0.75 (TS) and 0.4 (UDL), γQ = 1.35 and 1.15 (EN 1990, Annex A2).

Strip loads
Type Action q (kN/m²) Distance (m) Width (m) Remove

A strip is a distributed load of finite width, defined by its distance from the back of the wall and its width. What rests on the heel weighs on it, the rest pushes the virtual screen. Permanent loads are denoted G and variable loads Q.
